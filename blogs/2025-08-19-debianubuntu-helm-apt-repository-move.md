<p>If you are installing helm with Apt, be aware that the Debian/Ubuntu Helm Apt repository is moving.
Previously the repository was hosted at <a class="" href="https://helm.baltorepo.com/" rel="noopener noreferrer" target="_blank">Balto</a> and
now it will be hosted at <a class="" href="https://buildkite.com/" rel="noopener noreferrer" target="_blank">Buildkite</a>.</p>
<p>Update your APT key and references to the repository using the <a class="" href="https://helm.sh/docs/intro/install/#from-apt-debianubuntu" rel="noopener noreferrer" target="_blank">new installation instructions</a>.</p>
